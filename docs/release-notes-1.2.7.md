## v1.2.7 · 前台文案打磨

### 测试与升级说明

> 本版只调整前台「记得」页面的文案，**不含功能与数据变更**；装包后请强刷一次浏览器（Ctrl+Shift+R）。

### 改动（前台措辞更口语）

| 位置 | 原来 | 现在 |
|---|---|---|
| 页面副标题 | 记录值得纪念的日子、身边重要的人，还有陪你跑的爱车。 | 记着重要的日子、惦记的人，还有陪你跑的爱车。 |
| 牵挂的人 | 他们的生日与纪念日，都替你记着。 | 你惦记的人，生日都在这儿。 |
| 车主与驾驶人 | 谁开着哪辆车，都记在这里。 | 谁的车、谁常开，都记着。 |
| 空状态（爱车） | 还没添加爱车，先记一辆吧～ | 还没记爱车，先加一辆吧～ |
| 空状态（关联） | 还没有把人和爱车关联起来，去「座驾」里选一位车主吧～ | 还没给爱车配车主，去「座驾」里选一位吧～ |
| 空状态（日期） | 还没有记录。 | 还没有记录，先加一个吧～ |
| 空状态（人员） | 还没有添加。 | 还没有添加，先加一位吧～ |
