# 1.3.2 正式版说明 · 对外文案统一为「记得」

> 装包后请**强刷浏览器**（Ctrl+Shift+R）。本次仅文案调整，**功能与 1.3.1 完全一致**。

## 一、不再提旧名

插件更名已经过去多个版本，商店与插件页仍带着「原名『重要日期』」的说明。1.3.2 起**所有对外文案统一只讲「记得」**：

- 插件描述（Halo 插件页 / 应用市场）：由「记得 - **重要日期与爱车**：…」改为「记得 - **记日子、记人、记爱车**：…」；
- README（中 / 英）与商店 README：标题与更名说明段落一并去掉旧名；
- 应用市场的简介 / 描述 / 备用封面说明同步更新。

**保持不变**（改了会破坏升级或数据）：插件标识 `plugin-important-dates`、前台地址 `/important-dates`、jar 名与设置项名称。你原有的数据、设置与升级路径不受任何影响。

## 二、功能

与 `1.3.1` 相同 —— 即：悬浮提醒已修好并可设为**每次打开页面都提示**；座驾表单按车型只显示用得上的字段（电瓶车锁定纯电、自行车不留车牌与能源）；改车型保留数据、改回即恢复；提醒状态机（已办顺延、逾期待办、一键撤销）与隐私脱敏。

## 四、升级方式

- **Halo 2.26 及以上**；由 1.3.x 直接升级，**数据不会丢失**；
- 插件描述写在 jar 内，因此需要安装本版才会更新，**无法只靠改商店文案生效**；
- **完整重启 Halo 服务**，并清理 `plugins` 目录下其它 `plugin-important-dates-*.jar`，只保留新版；
- 浏览器强刷一次。
