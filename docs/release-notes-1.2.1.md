## 本次重点：座驾到期项更贴合真实车务

- **车辆级「保险公司」**：一辆车只需填一次保险公司（带常用公司快捷提示），交强险 / 商业险共用；个别险种可用「使用其他保险公司」单独覆盖
- **循环间隔可选**：每个到期项可设 **每年（12）/ 每两年（24）/ 每三年（36）/ 不循环 / 自定义月数**；「不循环」表示提醒一次后不再滚动
- **到期项表单精简**：一行一个项目——险种 / 保单号 / 到期日 / 提前提醒天数 / 循环间隔 / 启用
- **老数据幂等迁移**：启动时把旧数据里"每个险种各填一份的保险公司"提升为车辆级，并清理重复值；只读写插件自身的座驾数据，可重复执行

## 年检：按规则自动推算，可手动覆盖

- 未填写年检日期时，按「**首次登记日期 + 车型规则**」自动推算下一次年检：
  - 非营运小微型载客汽车：第 2、4 年**免检申领**标志 → 第 6、10 年**上线检验** → 第 11 年起**每年上线**
  - 摩托车：前 4 年每 2 年申领免检标志，之后每年上线检验（以当地车管所为准）
  - 电瓶车 / 自行车：通常无需年检，可按当地规定手动填写
- 提醒标题带阶段（如「年检·免检申领」），表单里显示推算结果与依据；缺少首次登记日期时会提示补填
- **可手动指定日期**：勾选后以手填日期为准（清空则不提醒年检）
- **提前 30 天提醒**（默认）：办理含上线检验通常需 2–3 个工作日，建议提前安排

## 年检 / 车船税默认「与保险同期」

- 两项默认跟随**交强险到期日**（联动显示、只读），保存时写入相同日期
- 取消勾选后可独立填写；尚未填交强险日期时给出提示，填好后自动联动

## 提醒与仪表盘

- **同车同日多事项合并**：同一辆车、同一天到期的交强险 / 商业险 / 车船税 / 年检合并为一条（如「小白 · 交强险 / 商业险 / 年检」），后台列表仍逐项显示
- **仪表盘小组件分页**：默认每页 5 条，可在「设置 → 展示设置」调整每页条数或关闭分页；组件显示**完整提醒列表**（不再受悬浮弹窗"每类最多 N 条"降噪限制），底部**始终显示**「共 X 条 · 每页 N 条」（关闭分页时只显示条数），翻页只切本地状态
- **一次性规则提示**：车辆按规则进入**上线检验期**（第 6 年起）或切换为**每年一次**（第 11 年起）时，后台座驾页顶部给出一次提示，点「知道了」后不再重复
- **过期更醒目**：小组件中已过期的提醒显示「已过期 N 天」（原先会显示为"今天"）

## 兼容与升级

- **Halo 2.26 及以上**（全新 2.26 实例全量回归 **50/50 PASS**；浏览器端到端 **13/13 PASS**，覆盖座驾表单、年检推算与手动覆盖、同期联动、仪表盘分页、提醒合并；老数据迁移幂等验证通过）
- 由 1.2.0 / 1.1.x 升级：停用 → 卸载 → 安装本版 → 启用，**数据不会丢失**（老数据自动迁移，幂等）
- **升级后请强刷一次浏览器（Ctrl+Shift+R / Cmd+Shift+R）**：Halo 控制台会缓存插件的控制台包；不强刷时可能出现「侧边栏没有『记得』、插件设置页签看不到、仪表盘小组件消失」等现象（实测确认，强刷即恢复，与服务端无关）
- 若主题目录存在自定义覆盖文件 `templates/important-dates.html`，请用仓库 `docs/theme-override/` 下最新版替换（或删除该文件使用插件默认模板）
- 使用页面缓存 / 静态化插件时，升级后清理一次页面缓存
