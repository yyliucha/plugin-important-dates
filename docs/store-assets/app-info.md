# 应用市场信息（编辑应用时直接复制）

> 用于 Halo 应用市场「编辑应用」表单。**描述字段为纯文本**：官方不支持 Markdown，请勿使用 `#`、`**`、`-` 等标记。
> 插件 ID 始终为 `plugin-important-dates`，更名不影响数据与升级。

## 一、应用名称

记得

## 二、列表简介（纯文本，一句话）

原名「重要日期」，1.2.0 起更名「记得」：记纪念日与生日（阳历/农历），也记爱车的保险、年检、保养到期，到点前提醒你；座驾按车型只显示用得上的项目（电瓶车锁定纯电、自行车不留车牌与能源），年检可按登记日期与车型规则自动推算，支持前台展示与隐私脱敏。

## 三、应用描述（纯文本，约 160 字；只讲作用）

「记得」帮你记下容易忘的事：值得纪念的日子、身边的家人朋友，以及爱车的保险、年检、保养到期日，到点前提醒你，愿意公开的可展示在博客前台。座驾按车型只显示用得上的项目——电瓶车锁定纯电、自行车不留车牌与能源；改车型时已有记录保留、改回即恢复；年检可按首次登记日期与车型规则自动推算，办完一键顺延；提醒可逐条忽略；图片失效时前台自动降级，不会出现破图。

## 四、更短的备选描述（约 90 字）

「记得」是一个记录与提醒插件：记下值得纪念的日子、身边的家人朋友，以及爱车的保险、年检、保养等到期日，到点前提醒你，愿意公开的内容可展示在博客前台。原名「重要日期」，1.2.0 起更名，插件标识、数据与前台地址均不受影响。
