# 应用市场信息（编辑应用时直接复制）

> 用于 Halo 应用市场「编辑应用」表单。插件 ID 始终为 `plugin-important-dates`，更名不影响数据与升级。

## 一、应用名称

**记得**（原名「重要日期」，1.2.0 起更名）

## 二、列表简介（一句话）

> 原名「重要日期」，1.2.0 起更名「记得」：记纪念日与生日（阳历/农历），也记爱车的保险、年检、保养到期——支持相册、前台双视图与隐私脱敏，零系统配置写入。

## 三、应用描述（简洁版，推荐）

**记得**（原名「重要日期」，1.2.0 起更名）——因为除了记日子，现在还替你记着爱车。

更名原因：新增完整的**座驾模块**与前台「生活 / 爱车」双视图，功能从"记日期"变成"记日子、记人、记爱车"。插件 ID 不变，**数据、设置、前台地址与升级路径都不受影响**。

**主要功能**
- 📅 **重要日期**：阳历 / 农历（含闰月）、每年自动循环、自研日期选择器、拖拽排序
- 👤 **人员**：生日、关系、大头贴（官方附件上传 / 附件库选择）、隐私脱敏
- 🚗 **座驾**：汽车 / 电瓶车 / 自行车；17 类分类、多图相册（逐张勾选是否前台展示）、保险 / 年检 / 保养等到期提醒、车主与驾驶人统一徽章
- 🔔 **三处提醒**：仪表盘小组件、后台 + 前台横幅、全站悬浮弹窗（位置 / 文案 / 倒计时可配）；提醒统一按"谁近谁靠前"排序
- 🖥 **前台页面**：`/important-dates` 单页「生活 / 爱车」切换，车辆相册点击全屏查看
- 🔒 **隐私与合规**：车牌号前台永远脱敏；敏感字段（体重 / 血型 / 身高 / 喜好 / 备注、VIN / 保单号等）永不输出；**零系统配置写入、零主题文件写入、无联网请求**
- 🧰 其他：操作日志（分页 + 自动清理）、JSON 导出导入、Finder API 供主题自定义

**兼容**：Halo **2.26+**（按官方 2.26 文档与扩展点实现；全新实例全量回归 44/44 通过）；MIT 开源。
