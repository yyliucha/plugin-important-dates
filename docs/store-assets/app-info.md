# 应用市场信息（编辑应用时直接复制）

> 用于 Halo 应用市场「编辑应用」表单：**应用名称**、**列表简介**、**应用描述**、**封面图**。
> 插件 ID 始终为 `plugin-important-dates`（更名不影响数据与升级）。

## 一、应用名称

**记得**

（原名「重要日期」，1.2.0 起更名）

## 二、列表简介（约 100 字，可粘贴到「简介」）

> 原名「重要日期」，1.2.0 起更名「记得」——因为除了纪念日与生日（阳历/农历），现在还替你管爱车：保险、年检、保养到期自动提醒，支持人员大头贴与座驾相册、前台「生活 / 爱车」双视图、隐私脱敏，零系统配置写入。

## 三、应用描述（详细版，整段粘贴）

**记得**（原名「重要日期」）帮你在后台记下值得纪念的日子、身边重要的人，还有陪你跑的爱车。

### 关于更名：为什么从「重要日期」改成「记得」
- **原名**：重要日期 —— 只描述了"日期"这一件事；
- **更名原因**：1.2.0 起插件新增了完整的**座驾（爱车）模块**：车辆档案、多图相册、保险/年检/保养到期提醒、车主与驾驶人关联，同时前台也从单页扩展为「生活 / 爱车」双视图。功能已从"记日期"变成"记日子、记人、记爱车"，旧名字装不下了；
- **「记得」的含义**：既保留"记得每一个重要日子"，也覆盖"记得给爱车做保养、记得年检、记得续保"——一句话就能记住它做什么；
- **不影响任何使用**：插件 ID（`plugin-important-dates`）保持不变，**更名不改变数据、设置、前台地址（仍为 `/important-dates`）与升级路径**，老用户直接升级即可，控制台菜单会显示为新名字。

### 📅 重要日期
- 名称 + 日期 + 多行备注；支持**阳历 / 农历（含闰月）**，农历自动换算当年阳历日期
- **每年自动循环**，列表直接显示"最近一次"是哪天、还有几天
- 自研日期选择器：阳历日历格内标注农历；农历可选年/月（含闰月）/日并实时换算；编辑时面板自动定位到已选日期
- **拖拽排序**：先后台保存，前台与仪表盘按同一顺序展示
- 重要/普通标识，重要日期参与提醒

### 👤 人员管理
- 姓名、昵称、关系（含"本人"）、生日（阳历/农历）、性别、血型、身高、体重、喜好、备注
- **大头贴**：使用官方附件能力上传或从附件库选择
- 重要日期可关联多人；人员列表可拖拽排序
- **隐私**：日期与人员各有"前台展示"开关；体重、血型、身高、喜好、备注在前台永不输出；生日默认脱敏（可在设置中关闭）

### 🚗 座驾（汽车 / 电瓶车 / 自行车）
- 车辆档案：品牌、车系型号、**17 类分类**（轿车、SUV、MPV、跑车、越野车、皮卡、旅行车、两厢车、跨界车、微面、房车、货车、客车、摩托车、**电瓶车、自行车**、其他）、能源类型、颜色、车牌号、VIN、发动机号、注册/购买日期、里程、状态（在用车/已出售/已报废）
- **多图相册**：上传或从附件库多选、拖拽排序、设封面；**每张可单独勾选"展示"**（未勾选仅后台可见，适合行驶证、保单等证件照）
- **到期提醒**：交强险、商业险、年检、保养（按上次保养 + 间隔月数推算）、车船税、驾照换证、自定义项；每项可设启用与提前天数；按年循环项到期后自动滚动到下一次；已出售/报废车辆不再提醒
- **关联人员**：车主与常用驾驶人可选，车辆卡片与人员卡片使用**统一徽章**（男生「酷」/ 女生「可爱」/ 未关联中性），并显示"车主 / 驾驶人"徽章
- **隐私**：**车牌号在前台永远脱敏**（如 `粤B·****5`）；VIN、发动机号、保单号、购买价格永不输出到前台；车辆"前台展示"默认关闭

### 🔔 到期提醒（三处可选）
- **控制台仪表盘小组件**（Halo 2.21+）：常驻提醒，每分钟自动刷新
- **后台 + 前台横幅**："「结婚纪念日」明天就到啦～"
- **全站悬浮弹窗**：位置自选（含屏幕中间）、倒计时 + 进度条、关闭方式菜单（本次 / 3 天 / 10 天 / 永久）
- 重要日期与座驾到期事项**统一排序（谁近谁靠前）**，悬浮弹窗每类最多显示 N 条、超出自动合并提示

### 🖥 前台页面
- 单页 **「生活 / 爱车」** 双视图切换（地址栏记忆）：
  - 生活视图：重要日期 + **牵挂的人**（生日与纪念日倒计时）
  - 爱车视图：车辆卡片（分类图标、**脱敏车牌**、到期徽章）+ **车主与驾驶人**（关系徽章含车名）+ 其他重要的人
- **相册查看**：点击车辆封面 → 全屏浮层滚动查看（只读），仅显示后台勾选"展示"的照片
- 通过官方**页面布局契约**复用主题外壳（主题不支持时使用 Halo fallback 布局）；主题可放置同名模板自行覆盖；**插件不写入、不修改任何主题文件**

### 📊 其他
- 操作日志：新增/编辑/删除全程记录，**分页浏览** + 按天自动清理（默认 30 天）
- 导出 / 导入：JSON 备份与迁移（含人员与座驾，兼容旧版导出文件）
- Finder API：`importantDateFinder`，主题可完全自定义展示

### 🔒 兼容与合规
- **Halo 2.26 及以上**（按官方 2.26 文档与扩展点实现；全新实例全量回归 44/44 通过）
- 数据存于站点数据库；**无任何联网请求、不采集用户数据**；MIT 开源
- 全站脚本经官方 `TemplateHeadProcessor` 输出；**零系统配置写入、零主题文件写入**
