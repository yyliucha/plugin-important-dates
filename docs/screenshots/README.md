# 截图清单（应用市场上架 / 仓库展示）

提交 Halo 应用市场前，把下列截图放到本目录，**文件名与 README 中的引用保持一致**（按下表命名即可，README 会自动显示）。

> 当前对应版本：**1.2.0（正式版；应用名「记得」，原名「重要日期」；此前的 1.2.0-SNAPSHOT 为开发/预发布版）**

## 通用拍摄要求

- 推荐尺寸 **1280×800 或 1920×1080**（16:9 或 4:3），PNG，单张 ≤ 2MB；
- 用**无痕窗口**拍摄（避免暴露真实姓名/生日/备注等个人信息）；数据用"演示数据"（如：结婚纪念日 / 宝宝生日 / 张三）；
- 界面主题用**亮色**（应用市场默认亮色展示，避免暗色看不清）；前后台截图风格尽量统一；
- 若截图里有个人隐私（真实家人姓名、真实车牌等），务必先改数据或打码——**注意：前台车牌会自动脱敏，后台截图请自行打码**；
- 仪表盘小组件截图前先完成添加：仪表盘 → 编辑仪表盘 → 添加部件 → 小部件中心 →（分组「**记得**」）→ 点击卡片 → 保存。

## 提交前自查（对照官方审核指南重点）

1. 在声明兼容的 Halo 版本（2.26）完成 安装→启用→配置→使用→禁用→卸载；
2. README、截图、版本说明、外部链接真实准确；
3. `plugin.yaml`：`logo`（自有）、`homepage`、`issues`、`license`、`requires: ">=2.26.0"` 均已设置；
4. 明确：插件不含联网请求、不采集用户数据、无需外部授权/付费能力（README 已写明）；
5. 命名空间合规：自有代码全部为 `com.yyliucha.importantdates`（审核材料见 `docs/app-store-resubmission.md`）；
6. 隐私自查：前台截图不得出现完整车牌、VIN、体重/血型等信息（插件已自动脱敏，截图仍建议复核）。
