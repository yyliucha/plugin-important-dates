# 1.3.0 正式版说明 · 座驾按车型分档，弹窗重构，并修掉一个会漏发的缺陷

> 装包后请**强刷浏览器（Ctrl+Shift+R）**：控制台会缓存插件的界面包，不刷新可能看不到新版表单。

## 一、修掉一个严重缺陷（1.2.6 引入，1.2.7 受影响）

后台「记得 → 座驾」卡片上的**交强险 / 商业险 / 车船税 / 保养到期标签整块消失**，只剩年检，卡片显示「暂无启用的到期项」。

**根因**：`resolveDueDate()` 末尾那一行 `return` 被写进了上一行的注释里，于是这个函数对所有**非年检**的到期项都返回空；而所有调用方都是"取不到就跳过"。

**为什么之前的测试没抓到**：仪表盘小组件与提醒状态机读的是**服务端接口**，而这个函数只在**控制台页面**里用——那条路径此前没有任何用例覆盖。现已修复，并补上了针对它的浏览器用例。

## 二、座驾表单按车型只显示用得上的字段

以「**有没有发动机、有没有牌照**」分档，不再把保险、年检、车船税一股脑塞给电瓶车和自行车：

| 控件 | 🚗 汽车 / 摩托等 | 🛵 电瓶车 | 🚲 自行车 |
|---|---|---|---|
| 能源类型 | 可选 | **锁定「纯电」**（只读） | **隐藏** |
| 车牌号 | 显示 | 显示 | **隐藏** |
| 车架号 | 显示 | 显示（改称「整车编号 / 车架号」） | **隐藏** |
| 发动机号 | 显示 | **隐藏** | **隐藏** |
| 首次登记日期 | 显示（年检推算用） | **隐藏** | **隐藏** |
| 当前里程 / 里程更新日期 | 显示 | 显示 | **隐藏** |
| 保险公司 | 显示 | **隐藏** | **隐藏** |
| 到期项可选 | 交强险/商业险/年检/保养/车船税/自定义 | 保养/自定义 | 保养/自定义 |

**「驾照换证」不再挂在座驾上**：它属于"人"而不是"车"，同一个人开两辆车时不会重复提醒。库里已有的项会保留，只是不再展示、也不再提醒。

## 三、改车型不丢数据

把汽车改成自行车时，已有的保险 / 年检项**不会被删除**：

- 表单里看不到（下拉里也没有该项）；
- 卡片、仪表盘小组件、前台横幅与悬浮弹窗**都不再提醒**；
- 改回汽车后**原样恢复**，到期日一个字都不改。

前后端用同一套规则判断"这个车型该不该提醒这一项"，**不改写你已存的数据**。

## 四、编辑弹窗不再那么长

- 分为**五个可折叠分区**：**基本信息**、**到期提醒**默认展开，**相册**、**关联人员**、**更多资料**默认收起，标题右侧还带摘要（如「3 张」「站长（孙铭）」）；
- 折叠用的是**浏览器原生 `<details>`**，展开收起由浏览器保证，不依赖脚本去改样式；
- 每条到期项从"两行三列 + 若干子块"压成**一行**，提前天数与循环间隔收进「设置」，收起时用一句人话概括（如「提前 15 天 · 每年」）。

## 五、老数据的能源显示纠偏

老车的能源类型多半是默认值「燃油」，自行车与电瓶车也会中招（卡片显示成「自行车 · 燃油」）。

现在**展示时按车型纠偏**：自行车 → 人力，电瓶车 → 纯电，机动车若残留「人力」→ 燃油。
**不改写已存数据**，只是把显示纠正过来；在表单里保存一次会把归一后的值存下来。

## 六、清理掉已经不可达的代码

- 移除自检面板、操作日志弹窗及其全部调用点（入口在 1.2.6 已删除，只剩空转的空实现）；
- 删除 `selfCheck.ts`、`OperationLog.java`、`OperationLogCleaner.java`（后者读的 `log` 设置组早已不存在，等于每次空跑）；
- 顺带修正 `plugin.yaml` 的描述——之前还在宣传已移除的「操作日志」。

## 七、验证

在真实 Halo 2.26 实例上，**复用既有数据**（含 10 辆历史车辆）执行：

| 套件 | 结果 |
|---|---|
| 功能自测 `func-128.mjs` | **18/18 PASS** |
| 前台回归 `func-frontend.mjs` | **5/5 PASS** |

覆盖：卡片到期项（上述缺陷的回归用例）、车型字段联动、能源锁定、**切车型保存不丢数据**、折叠分区不占位与点击展开收起、后端提醒接口按车型过滤、老数据能源纠偏、前后台无 JS 报错。

自测过程中另外揪出并修掉了两个问题：**车型不适用的项仍在报警**（此前只做到"表单不显示"）、**老数据能源显示错误**。

## 八、升级方式

- **Halo 2.26 及以上**；由 1.2.x 直接升级即可，**数据不会丢失**，无需迁移脚本；
- 若主题目录存在 `templates/important-dates.html` 覆盖文件，建议用仓库 `docs/theme-override/` 下最新版替换（本版未改动前台车卡结构）；
- 装包后请强刷一次浏览器。
