## v1.2.0-SNAPSHOT 预发布（开发中）

> ⚠️ 这是**预发布版本**：座驾（爱车）模块已可完整体验，插件仍在开发中，后续会持续迭代并发布正式版 `1.2.0`。
> **应用更名**：原名「重要日期」→ 现名「**记得**」。原因：功能已从"记日期"扩展到"记日子、记人、记爱车"（新增座驾模块与前台双视图），旧名字装不下；插件 ID（`plugin-important-dates`）不变，**更名不影响数据、设置、前台地址（仍为 `/important-dates`）与升级路径**。

### 🚗 本版新增：座驾（汽车 / 电瓶车 / 自行车）
- **车辆档案**：品牌、车系型号、**17 类分类**（轿车 / SUV / MPV / 跑车 / 越野车 / 皮卡 / 旅行车 / 两厢车 / 跨界车 / 微面 / 房车 / 货车 / 客车 / 摩托车 / **电瓶车 / 自行车** / 其他）、能源类型（燃油 / 纯电 / 插混 / 油电混动 / 人力）、颜色、车牌号、VIN、发动机号、注册/购买日期、里程、状态（在用车 / 已出售 / 已报废）
- **多图相册**：上传或从官方附件库多选、拖拽排序、设封面；**每张可单独勾选「展示」**（未勾选仅后台可见，适合行驶证、保单等证件照）
- **到期提醒**：交强险、商业险、年检、保养（按上次保养 + 间隔月数推算）、车船税、驾照换证、自定义项；每项可设置启用与提前天数；按年循环项到期后自动滚动到下一次；已出售/报废车辆不再提醒
- **关联人员**：车主（单选）与常用驾驶人（多选）可选，车辆卡片与人员卡片使用**统一徽章**（男生「酷」/ 女生「可爱」/ 未关联中性），并显示「车主 / 驾驶人」徽章
- **拖拽排序**：车辆列表可拖拽排序，前后台顺序一致

### 🖥 前台：「生活 / 爱车」双视图
- 页面顶部切换（`?view=car` 记忆），选中态高对比（对比度 5.17，达 WCAG AA）
- **生活视图**：重要日期 + **牵挂的人**（生日与纪念日倒计时）
- **爱车视图**：车辆卡片（分类图标、脱敏车牌、到期徽章）+ **车主与驾驶人**（关系徽章含车名，如「🚗 车主 · 小白」）+ **其他重要的人**（未与爱车关联的家人朋友，不消失）
- **相册查看**：点击车辆封面 → 全屏浮层滚动查看（只读，Esc / ✕ 关闭），仅显示后台勾选「展示」的照片

### 🔒 隐私与合规
- **车牌号前台永远脱敏**（如 `粤B·****5`，不提供完整显示开关）；VIN、发动机号、保单号、购买价格**永不输出到前台**；未勾选「展示」的照片不出现在前台
- **零系统配置写入、零主题文件写入**；全站脚本经官方 `TemplateHeadProcessor` 输出；无任何联网请求、不采集用户数据

### ✨ 同期改进（相对 1.1.5）
- 到期提醒统一管线：重要日期与座驾到期**同一列表按剩余天数升序**（谁近谁靠前），悬浮弹窗每类最多 N 条、超出自动合并提示
- 编辑日期/人员时日历面板自动定位到已选日期；人员关系新增「本人」
- 操作日志分页浏览 + 按天自动清理；导入导出升级 **JSON v3**（包含座驾与相册，兼容旧文件）
- 设置页「照片设置」统一管理人员大头贴与座驾相册的附件分类 / 存储策略（选项实时同步系统真实数据）

- 浏览器端到端：附件库多选入相册 → 逐张「展示」勾选 → 保存落库 → 前台零泄露；前台双视图切换、相册浮层、性别统一徽章均验证通过

### ⬆️ 升级提示
- 由 1.1.x 升级：停用 → 卸载 → 安装本版 → 启用（数据不会丢失）
- 主题若放置了 `themes/主题名/templates/important-dates.html` 覆盖文件，请用仓库 `docs/theme-override/` 下最新版替换（或删除该文件使用插件默认模板），否则前台看不到「爱车」视图
- 若使用页面静态化/缓存插件，升级后清理一次页面缓存
