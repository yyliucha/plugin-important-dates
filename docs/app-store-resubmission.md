## 一、差异化说明（"没有重复实现"）

本插件 **不是图片类/工具类插件的重复实现**，核心是"数据管理 + 隐私 + 主题内自动展示"：

- **业务定位**：纯后台的"重要日期（纪念日/生日）+ 人员档案"数据管理，与任何图片图库、素材类插件（如 Pixabay 图库）功能 **零交集**：本插件不请求任何外部网络、没有图片素材、没有图床/搜索功能。
- **独立能力组合**（商店内唯一同时具备）：
  - 阳历 + 农历（含闰月）双历日期，每年自动循环换算（依赖 lunar 库）
  - 人员档案（姓名/昵称/关系/生日/血型/身高/体重/喜好/备注），日期可关联多人、按人筛选
  - 到期提醒：插件后台横幅 + 前台 `/important-dates` 页横幅 + 全站悬浮提示（位置可选 右下/左下/右上/左上/底部居中/屏幕中间，设置驱动、自动注入站点全局 head，公开 JSON 接口）
  - **隐私双维度**：日期/人员各自的"前台展示"开关；敏感字段（体重/血型/身高/喜好/备注）字段级永不出现在前台；生日默认脱敏（`1990-05-**`）可配置
  - **主题内自动展示**：自动探测主题布局并生成适配模板（带版本标记、自动升级、失败回退不自带页不 500），无需用户手动配置
  - 操作日志、导出/导入（JSON，判重跳过）
- 结论：功能是**新增品类**（"个人重要日期管理"），非现有插件的功能子集。
