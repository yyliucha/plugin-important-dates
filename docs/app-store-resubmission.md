# 应用商店上架审核材料（v1.1.2）

供 Halo 应用市场审核参考。本版按 2026-09 审核意见完成整改（整改说明见文末），并提供人工测试清单与自动化回归记录。

## 一、差异化说明

本插件为「个人重要日期管理」品类：后台记录重要日期与家人朋友（结婚纪念日、孩子出生日期等），与图片图库/素材类插件功能零交集。独有的能力组合：

- 阳历 + 农历（含闰月）双历日期，每年自动循环换算（依赖本地库 cn.6tail:lunar）
- 人员档案（姓名/昵称/关系/生日/血型/身高/体重/喜好/备注），日期关联多人、按人筛选
- 到期提醒：控制台仪表盘小组件（常驻、无关闭、每分钟刷新）+ 后台/前台横幅 + 全站悬浮弹窗（位置配置、倒计时、关闭方式菜单）
- 隐私：日期/人员各自「前台展示」开关；敏感字段字段级永不出现在前台；生日默认脱敏
- 前台页面：插件自带默认模板，主题可选覆盖（TemplateNameResolver）；操作日志、导出/导入（判重跳过）

## 二、命名空间与依赖合规

- 自有 Java 代码全部位于 `com.yyliucha.importantdates`（不含 `run.halo.*` 自有命名空间）；自查 `run.halo.importantdates` 匹配 0
- 仅使用官方依赖坐标：`run.halo.tools.platform:plugin`、`run.halo.app:api`（compileOnly）、`cn.6tail:lunar`
- 插件无任何联网请求、不采集/不上传用户数据；License MIT

## 三、审核意见整改说明（1.1.2）

| 审核意见 | 整改 |
|---|---|
| ① 禁止直接读写 System ConfigMap codeInjection | ✅ 已移除对 System ConfigMap 的全部读写。全站脚本改由官方 **`TemplateHeadProcessor`** 扩展点按设置输出：设置关闭 → 不输出；插件停用/卸载 → 处理器随插件卸载，自动消失。静态脚本经官方 **ReverseProxy** 提供（`/plugins/plugin-important-dates/assets/...`）。冒烟断言：开启/关闭前后 System ConfigMap `codeInjection` 字节级一致（零写入） |
| ② 禁止请求线程同步文件操作 + 主题文件残留 | ✅ 已删除主题模板自动生成/升级机制（不再写 `themes/主题名/templates/`）。前台页改用**插件自带 Thymeleaf 默认模板**（`resources/templates/important-dates.html`）+ 官方 **TemplateNameResolver**（主题提供同名模板则用主题模板 = 主题自定义增强，插件永不写主题文件）。冒烟断言：全流程后主题目录无任何插件生成文件（零残留）；页面渲染为纯内存模板，无阻塞文件 IO |
| ③ 兼容范围不一致 | ✅ 统一为 **`>=2.20.0`**（plugin.yaml `requires`、README、版本说明、表单一致）。依据：基于 2.20 平台 API 编译；**2.20.20 与 2.26.0 各 36/36 全流程实测通过**；2.14–2.19 未验证，故最低兼容版本以实测 2.20 为准 |
| ④ 重复制品 | ✅ 表单内删除重复制品，每版本仅保留 `plugin-important-dates-1.1.2.jar` 一份 |
| ⑤ AI 参与的人工测试 | ✅ 见下节「测试记录与人工清单」 |

- **Halo 2.20.20 全新实例：36/36 PASS**

覆盖：安装/启用 → 前台默认模板渲染（且**主题目录零写入**）→ 日期 CRUD（阳历/农历闰月）→ 人员 CRUD（体重最新值）→ 关联多人/按人筛选 → 隐藏人员不泄露 → 提醒 JSON → **悬浮提醒：默认关闭页面无脚本 / 开启后 TemplateHeadProcessor 输出脚本且 System ConfigMap 零写入 / 关闭后页面不再输出** → 操作日志 → 导入判重 → 导出回读 → 隐私字段不泄露 → 生日脱敏 → 昵称 → 悬浮秒数 → 横幅/可见性 → **主题目录零残留**。

### 浏览器人工验证（Chrome 实测，截图留档）

- 仪表盘小组件：小部件中心 →「重要日期」分组 → 添加 → 保存 → 常驻显示
- 悬浮弹窗：居中弹窗 + 倒计时 + 进度条；关闭方式菜单（本次/3天/10天/永久）；3 天记录→刷新不弹→到期自动恢复；永久关闭→刷新不弹→清 key 恢复
- 后台：日期/人员列表、新增弹窗（阳历农历选择器）、操作日志弹窗、设置页（全站悬浮提醒组）、导出导入
- 删除后列表立即刷新（本地即时移除 + deletionTimestamp 过滤，与 Halo 官方列表行为一致）
