## 修复：附件库「分类 / 策略」范围不再显示空白

- **问题**：座驾相册与人员大头贴的「从附件库选择」原先要求 **分类 + 策略同时命中**。站点里只要有一项与实际数据不一致（图片没有分组、或用了别的存储策略），列表就会是空的——人员大头贴弹窗甚至只显示一个空白框，看起来像"设置没生效"。
- **现在**：优先按「分类 + 策略」过滤；**命中为空时自动放宽**为「仅分类」→「仅策略」→「全部图片」，并在弹窗顶部用一行说明当前生效范围与各自命中数，例如：
  `设置中「分类 + 策略」没有同时命中的图片，已放宽为仅按分类显示 12 张（分类「文章插图」命中 12 张 · 策略「大头贴」命中 0 张）`
- **「未分组」正确匹配**：设置里的「未分组」现在按"没有分类的图片"处理（此前被当成一个真实分组名去比对，必然 0 张）。
- **不再自动选第一个分类 / 策略**：旧行为在未配置时会静默把附件库收窄到某个分类 + 策略（正是"看起来没生效"的来源）；现在未配置就是「不限定」，显示全部图片。已保存但已失效的分类 / 策略（分组被删除等）会自动回到「不限定」。
- **上传归档不变**：仍按设置的分类 / 策略存放；分类为「未分组」时不提交分组名（避免把 `__ungrouped__` 当成真实分组）。
- **界面**：范围说明单独一行，长文案不再挤压弹窗标题；底部仍显示「当前显示 N 张 · 附件库共 M 张图片」，并提供「显示全部图片（忽略分类 / 策略）」开关。
