## 修复：后台「座驾」页签的车辆卡片恢复紧凑布局（封面不再铺满屏幕）

- **现象**：给车辆相册加了照片后，后台「座驾」页签里的封面图被拉成整屏大小（实测 1920×1080 的原图渲染成 1180×664，卡片本身 1212×836），几乎铺满屏幕。
- **根因**：`console/src/views/ImportantDatesView.vue` 的样式块被提前闭合——约 3KB 的 CSS（`.cars-grid` / `.car-card` / `.car-cover` / `.car-events` / `.rule-notice` / `.person-avatar-char` 等）落在了 `</style>` **之后**，构建时被整体丢弃，于是这些规则从未生效；没有照片时卡片看起来"还行"，加了照片就暴露出来。
- **修复**：把样式块闭合位置修正到文件末尾，全部规则重新生效。
- **效果（实测）**：卡片 1212×836 → **395×191**；封面 1180×664 → **84×62**（`object-fit: cover` 裁切，原图多大都不影响）；座驾列表恢复 **多列网格**，到期徽章（已过期 / N 天后）、车主与驾驶人、编辑/前台展示/删除按钮恢复设计中的紧凑样式。
