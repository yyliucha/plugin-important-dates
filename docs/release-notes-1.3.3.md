# 1.3.3 正式版说明 · 弹窗学会「少抛决定」，永久静音成为历史

> 装包后请**强刷浏览器（Ctrl+Shift+R）**，并**完整重启一次 Halo 服务**（仅替换 jar 不重启，Halo 会继续用内存里的旧代码）。

## 一、弹窗不再一次抛给你一堆决定

开着提醒却没人看，通常不是提醒不够多，而是**一次给得太多**。这一版把弹窗从「清单」改回「提醒」：

- **一辆车只占一行**：显示最近到期的那一项，并注明「**这辆车共 N 项到期**」。
  在此之前，交强险、商业险、车船税、年检各占一行 —— 明明是同一个动作（续保 / 去办），却被拆成 4 个决定，用户只能自己判断"这是不是一件事"。
- **被折叠的汇总成「还有 N 项」**：既包括被折叠的座驾项，也包括超出「每类最多 N 条」的项。这个数字**只数真正被限制挡掉的那些**，逾期 / 已办 / 还没到期这类本来就不该出现在弹窗里的项不会混进来，不会虚高吓人。
- **底部一行可点文字直达「记得」页**：在后台浏览时跳后台「记得」，在网站前台浏览时跳前台「记得」页，文案可在设置里改。

完整日期**没有消失**：前台横幅、仪表盘小组件与「记得」页始终逐条显示每一辆车的每一项。弹窗只负责提醒，清单在别处。

## 二、「永久不再提示」已经拿掉

之前关闭菜单里唯一的"彻底安静"选项是「永久关闭」，代价是**手一滑就再也收不到提醒**，而且因为菜单本身没有反馈，用户只会觉得"这插件坏了"。

现在所有选项都有期限：

- 菜单为 **本次关闭 / 今天不再提示 / 3 天内不显示 / 5 天内不显示 / 7 天内不显示 / 30 天内不显示**；
- 天数可在设置里改（默认 `3,5,7,30`），菜单由服务端按设置下发，改设置不用改脚本；
- **老访客不会被永久拉黑**：1.3.1 及更早版本可能在他们浏览器里写下过永久静音标记，新脚本读到就清掉；
- 万一遇到认不出来的取值，一律退回「本次关闭」，**绝不会变成永久静音**。

## 三、弹窗出现频率可限制

弹窗出现太频繁时，可在设置里限制：**每次打开页面都提示 / 每天最多 N 次 / 每 N 分钟最多一次**（限制按访客浏览器记录，跨设备各自计算）。

## 四、修掉一个真问题：座驾「自定义」到期项从不提醒

车型能力表里漏了「自定义」，导致自定义到期项（例如"换轮胎"）建得出来、也存得下，却**永远不参与提醒**。这是 1.3.0 做车型分档时引入的回归，现在汽车的自定义项会正常提醒。

## 五、设置说明不再"说了不算"

- 「× 关闭默认行为」明确标注**只在「关闭方式菜单」开启时生效**（菜单关闭时点 × 只是收起当前弹窗，这是刻意设计，避免静默静音）；
- 弹窗相关帮助文字与实际行为对齐（此前还在描述"记录写库"这类早已移除的行为）。

## 六、关于升级方式（踩过的坑）

**不要手工替换 plugins 目录里的 jar。** Halo 会在数据库里记录每个插件的加载路径，手工换掉文件后它仍指向旧文件名，插件会直接不加载（表现为接口 404、后台菜单消失）。正确做法是在「插件」页面上传新 jar 升级，或让 Halo 自己完成升级流程。
