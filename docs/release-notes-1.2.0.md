## v1.2.0 正式版 · 记得（重要日期与爱车）

> 应用显示名由「重要日期」更名为「**记得**」——功能不变、数据不变，插件 ID（`plugin-important-dates`）保持不变，升级/覆盖安装即可。

### 🚗 新增：座驾（汽车 / 电瓶车 / 自行车）
- **车辆档案**：名称/昵称、品牌、车系型号、**17 类分类**（轿车 / SUV / MPV / 跑车 / 越野车 / 皮卡 / 旅行车 / 两厢车 / 跨界车 / 微面 / 房车 / 货车 / 客车 / 摩托车 / **电瓶车 / 自行车** / 其他）、能源类型（燃油 / 纯电 / 插混 / 油电混动 / 人力）、颜色、车牌号、VIN、发动机号、注册/购买日期、里程、状态（在用车 / 已出售 / 已报废）
- **多图相册**：上传或从官方附件库多选、拖拽排序、设封面；**每张可单独勾选「展示」**（未勾选仅后台可见，适合行驶证、保单等证件照）
- **到期提醒**：交强险、商业险、年检、保养（支持按上次保养 + 间隔月数推算）、车船税、驾照换证、自定义项；每项可单独设置启用与提前天数；**按年循环项到期后自动滚动到下一次**；已出售/报废车辆不再提醒
- **关联人员**：车主（单选）与常用驾驶人（多选）可选；关联后车辆卡片与人员卡片使用**统一徽章风格**（男生「酷」/ 女生「可爱」/ 未关联中性），并显示「车主 / 驾驶人」徽章
- **隐私**：**车牌号前台永远脱敏**（如 `粤B·****5`，不提供完整显示开关）；VIN、发动机号、保单号、购买价格**永不输出到前台**；车辆「前台展示」默认关闭
- **拖拽排序**：车辆列表支持拖拽调整顺序，前后台一致

### 🖥 前台：单页「生活 / 爱车」双视图
- 页面顶部切换「**生活 / 爱车**」，切换写入 URL（`?view=car`，刷新与分享保持）
- **生活视图**：重要日期 + **牵挂的人**（他们的生日与纪念日倒计时）
- **爱车视图**：车辆卡片（分类图标、脱敏车牌、到期徽章）+ 爱车到期横幅（"「小白」的交强险还有 7 天到期，记得安排一下呀～"）+ **车主与驾驶人**（关系徽章含车名，如"🚗 车主 · 小白"）+ **其他重要的人**（未与爱车关联的家人朋友，不消失）
- **相册查看**：点击车辆封面 → 全屏浮层滚动查看（只读，Esc / ✕ 关闭），仅显示后台勾选「展示」的照片
- **人员两种视图都显示**：生活视图看生日/纪念日倒计时，爱车视图看与爱车的关系（车主 / 驾驶人），信息随视图变化

### ✨ 其他改进
- 到期提醒统一管线：重要日期与座驾到期**同一列表按剩余天数升序**（谁近谁靠前），悬浮弹窗每类最多显示 N 条、超出合并提示
- 编辑日期/人员时，日历面板自动定位到已选日期；人员关系新增「本人」
- 操作日志分页浏览 + 按天自动清理；导入导出升级为 **JSON v3**（包含座驾与相册，兼容旧文件）
- 设置页「照片设置」统一管理人员大头贴与座驾相册的附件分类/存储策略（选项实时同步系统真实数据）

### 🔒 兼容与合规
- **Halo 2.26+**（按官方 2.26 文档与扩展点实现；全新 2.26 实例全量回归 **44/44 通过**）
- 数据存于站点数据库；插件**无任何联网请求、不采集用户数据**；MIT 开源
- 全站脚本经官方 `TemplateHeadProcessor` 输出；**零系统配置写入、零主题文件写入**

### ⬆️ 升级提示
- 由 1.1.x 升级：停用 → 卸载 → 安装 1.2.0 → 启用；**数据不会丢失**（记录存于站点数据库）
- 应用更名仅影响显示名，控制台菜单会变为「记得」；前台地址仍为 `/important-dates`
- 主题自定义覆盖文件（`themes/主题名/templates/important-dates.html`）如需爱车视图与新样式，请用仓库 `docs/theme-override/` 下最新版本替换，或删除该文件使用插件默认模板
- 若使用页面静态化/缓存插件，升级后清理一次页面缓存
