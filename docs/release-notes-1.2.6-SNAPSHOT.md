# 1.2.6 开发版说明 · 提醒状态机（逾期 3 天 · 已办 · 忽略 · 节点式）

> ⚠️ **开发版（1.2.6-SNAPSHOT）**，先给你测；确认后我再出正式版。
> 装包后请**强刷浏览器（Ctrl+Shift+R）**。

## 一、为什么改

之前只有"提醒"、没有"办没办"：过期后的内容照样每天提示，而且**满 30 天会直接消失**（真正没办的事反而被忘掉）；同时"我做过了但前台还在显示"也没法处理。

现在补上**状态**：**到期日只决定处于哪个阶段，状态只由你的操作决定**——插件不自动顺延、不猜测你办没办。

## 二、四个状态

| 状态 | 判定 | 后台（你看） | 前台（横幅 / 悬浮提示） |
|---|---|---|---|
| 待办 | 在提醒窗口内 | 显示 | 显示 |
| **已逾期** | 逾期 1 ~ 3 天（可配） | **红色置顶**，每天文案不同 | **不显示** |
| **待处理** | 逾期超过 3 天（可配） | 橙色「待处理」，**不再主动提醒但不消失**，计入总览 | 不显示 |
| 已办 / 已忽略 | 你点了按钮 | 显示「已办 · 时间（原到期日）」/「本周期已忽略」 | 不显示 |

## 三、你要的操作（这是唯一会改变状态的方式）

- **✓ 已办**：循环项 → **到期日按循环间隔顺延一期**（例：交强险 2026-01-10 → 2027-01-10），并记录「哪天办的、从哪天滚到哪天」，写进操作日志；一次性项 → **标记完成，不再提醒**。
- **✕ 忽略**：本周期不再提醒（存在库里，换浏览器依然有效）；**到期日一变就自动恢复**提醒。
- **↺ 恢复**：撤销忽略 / 撤销完成，重新开始提醒。
- 入口：后台「座驾」页签每条到期项右侧；仪表盘小组件每条提醒右侧。

## 四、逾期文案（逐日不同）

| 阶段 | 文案 |
|---|---|
| 还有 15 天 | 「小白」的交强险还有半个月到期，可以先安排一下 |
| 还有 7 天 | 「小白」的交强险还剩一周，记得抽空办 |
| 还有 3 天 | 「小白」的交强险还有 3 天就到期了 |
| 还有 1 天 | 「小白」的交强险明天到期 |
| 当天 | 「小白」的交强险就是今天到期，别忘了处理哦 |
| 逾期第 1 天 | 「小白」的交强险昨天到期了，记得安排一下~ |
| 逾期第 2 天 | 「小白」的交强险已经逾期 2 天，别忘了办呀 |
| 逾期第 3 天 | 「小白」的交强险逾期 3 天了，尽快抽空处理吧（这是最后一次主动提醒，之后可在后台查看） |
| 第 4 天起 | 已逾期 N 天 · 待处理（不再主动提醒，保留在列表） |

纪念日/生日的文案**保持原样**（「就是今天呀 🎉」「明天就到啦～」），不受本次改动影响。

## 五、悬浮提示改为「节点式」，并且只在本页面弹出

- **节点式**：进入提醒期后按 **还有 15/7/3/1 天 → 当天 → 逾期 1/2/3 天** 这些节点提醒，**每个节点只弹一次**；同一天反复刷新、关掉浏览器重开、换设备都不再重复（记录写在数据库里，不随浏览器重置）。
- **作用域改为「只在记得页面弹出」**（你选的方案 C）：访客浏览站点其它页面不会再看到站主的提醒。
- 逾期项**不会出现在前台**（横幅 + 悬浮提示都不显示）；需要让家人也看到时可打开「提醒设置 → 前台显示逾期项」。

## 六、顺手修掉的一个老 Bug（重要）

开启「全站悬浮提醒」后，注入的脚本标签用的是自闭合写法（`<script ... />`），HTML 解析器不会自闭合 `<script>`，会把**后续整段页面内容当成脚本文本吞掉** —— 表现就是**「记得」页面内容整块消失，只剩悬浮提示**。1.2.6 改为成对的 `<script ...></script>` 输出，问题修复。

## 七、新增设置

| 设置 | 默认 | 说明 |
|---|---|---|
| 提醒设置 → 逾期后继续提醒天数 | 3 | 超过后转「待处理」：不再主动提醒，但一直保留在列表直到你处理（1–30 天可配） |
| 提醒设置 → 前台显示逾期项 | 关 | 打开后前台也显示逾期项（默认只显示"即将到期且未办理"） |
