# 1.3.0 开发版说明 · 车型分档联动 + 编辑弹窗重构 + 一个严重缺陷修复

> ⚠️ **开发版（1.3.0-rc.1）**，先给你测；确认后我再出正式版 1.3.0。
> 装包后请**强刷浏览器（Ctrl+Shift+R）**。

## 一、修掉一个严重缺陷（1.2.6 引入，1.2.7 已发布版本受影响）

`console/src/utils/vehicle.ts` 里有一行 `return` 被写进了注释末尾，导致 `resolveDueDate()` 对**非年检的到期项**直接返回 `null`。所有调用方都写着"拿不到就跳过"，于是：

**后台「记得 → 座驾」的卡片上，交强险 / 商业险 / 车船税 / 保养的到期标签整块消失，只剩年检**，卡片显示「暂无启用的到期项」。

为什么之前的测试没抓到：仪表盘小组件和提醒状态机测的都是**后端接口**，而这个函数只在**控制台页面**里用。这条路此前没有任何用例覆盖。

现已修复，并补了针对它的浏览器用例（本版自测 D1a）。

## 二、车型分档联动（电瓶车 / 自行车不再被塞进保险和年检）

按「有没有发动机、有没有牌照」分档，表单只显示适用的字段：

| 控件 | 🚗 汽车/摩托等 | 🛵 电瓶车 | 🚲 自行车 |
|---|---|---|---|
| 能源类型 | 可选 | **锁定「纯电」** | **隐藏** |
| 车牌号 | 显示 | 显示 | **隐藏** |
| 车架号 | 显示 | 显示（叫「整车编号 / 车架号」） | **隐藏** |
| 发动机号 | 显示 | **隐藏** | **隐藏** |
| 首次登记日期 | 显示 | **隐藏** | **隐藏** |
| 当前里程 / 里程更新日期 | 显示 | 显示 | **隐藏** |
| 保险公司 | 显示 | **隐藏** | **隐藏** |
| 到期项可选 | 交强险/商业险/年检/保养/车船税/自定义 | 保养/自定义 | 保养/自定义 |

**「驾照换证」已从座驾到期项中移除**（它是"人"的事，同一人开两辆车会重复提醒）。

## 三、改车型不丢数据（保留但不再打扰）

把车从汽车改成自行车时，已有的保险/年检项**不会被删除**，而是"保留不展示"：

- 表单里不再出现（下拉里没有该项，行也不显示）；
- **卡片、仪表盘小组件、前台横幅/弹窗都不再提醒**（车型不适用的项不参与提醒）；
- 改回汽车后**原样恢复**，到期日一个字都不变。

后端与前端用同一套规则过滤（`VehicleSupport.supportsReminder` / `vehicleSupportsReminder`），数据本身不做任何改写。

## 四、编辑弹窗不再那么长

- 五个分区：**基本信息 / 到期提醒**默认展开，**相册 / 关联人员 / 更多资料**默认收起，标题右侧显示摘要（如「3 张」「站长（孙铭）」）；
- 折叠用的是浏览器原生 `<details>/<summary>`，展开收起由浏览器保证，不依赖脚本改样式；
- 每条到期项从"两行三列 + 若干子块"压成**一行**，细节收进「设置」；收起时用一句人话说清（如「提前 15 天 · 每年」）。

## 五、老数据的能源显示纠偏

老车的能源类型多半是默认值「燃油」，自行车/电瓶车也会中招（显示成「自行车 · 燃油」）。

现在**展示时按车型纠偏**：自行车 → 人力，电瓶车 → 纯电，机动车若残留「人力」→ 燃油。
**不改写你已存的数据**，只是显示正确；打开表单保存一次会把归一后的值存下来。

## 六、清理掉已经不可达的代码

- 移除自检面板、操作日志弹窗及其全部调用点（入口在 1.2.6 已删，只剩空转的空实现）；
- 删除 `selfCheck.ts`、`OperationLog.java`、`OperationLogCleaner.java`（它读的 `log` 设置组早已不存在，等于空转）；
- 顺带修正 `plugin.yaml` 的描述——之前还在宣传已移除的「操作日志」；
- 前端包因此小了一圈。

## 七、验证（真机自测，不是静态检查）

在真实 Halo 2.26 实例（复用已有数据目录，含 10 辆历史车辆）上跑：

| 套件 | 结果 |
|---|---|
| **功能自测 `func-128.mjs`** | **18/18 PASS** |
| **前台回归 `func-frontend.mjs`** | **5/5 PASS** |

覆盖：卡片到期项（I1 回归）、车型字段联动、能源锁定、**切车型保存不丢数据**、折叠分区不占位、点击展开收起、后端提醒接口过滤、老数据能源纠偏、前后台无 JS 报错。

自测过程中另外揪出并修掉了两个问题：**车型不适用的项仍在报警**（只做到"表单不显示"）、**老数据能源显示错误**。

## 八、兼容与升级

- **Halo 2.26 及以上**；
- 由 1.2.7 升级：直接在插件页升级即可，**数据不会丢失**；
- 若主题目录存在 `templates/important-dates.html` 覆盖文件，建议用仓库 `docs/theme-override/` 下最新版替换（默认模板未改动车卡结构）。
