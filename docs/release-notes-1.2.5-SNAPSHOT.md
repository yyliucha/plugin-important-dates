## 新能力：图片引用失效时自动降级，并在后台标出来

**背景**：插件里存的是**附件的访问地址**（座驾相册 `photos[].url`、人员大头贴 `avatar`）。附件在 Halo「附件」里被删除、存储策略变化，或被**其它插件的全局规则拦截**（例如防直链类插件把 `/upload/**` 变成 404）之后，这些地址就会失效——前台/后台随即出现"裂图"，而且很难知道是哪条记录在引用它。

**现在做了三件事**：

1. **前台自动降级（访客永远看不到破图）**
   - 车辆封面失效 → 回退为车型图标（`🚙` 等），卡片排版不变；
   - 人员大头贴失效 → 回退为首字头像（与"未设置大头贴"时的表现一致）；
   - 相册浮层里的失效图 → 显示「图片已不可用（附件可能已被删除）」占位卡片，其余照片正常浏览。
2. **后台直接标出来**
   - 车辆卡片：`含失效图片 N` 标签；人员卡片：`大头贴已失效` 标签；
   - 座驾表单的相册行：失效缩略图显示 🚫 占位 + 「图片已不可用（附件可能已被删除），请移除或重新选择」，可一键「移除」或重新选图。
3. **检测方式足够轻**：打开列表时**批量取一次附件清单**做比对（不是每张图发一次请求）；**只有本站 `/upload/**` 地址**参与判断，外部图片地址一律不标记，**取不到附件清单时不做任何标记**（避免误报）。

> 说明：这是"事后发现 + 优雅降级"，**不会阻止你删除附件**；如果你确实不再使用某个附件，按标记移除/换图即可。
