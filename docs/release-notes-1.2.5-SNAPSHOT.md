## 一、稳定性：写操作全部收口（不再被反向代理限流打回）

- **只改变化字段**：单字段操作（前台展示开关、年检提示确认、拖拽排序…）统一改用 **JSON Patch**，不再「GET 最新版本 → PUT 整个对象」，请求数减半；
- **批量写串行**：所有批量提交都串行 + 固定间隔，绝不并发打出一串请求；整对象保存（表单）也带 **409 自动重取版本重试**；
- **429 / 5xx 退避重试**：所有写操作对限流与网关错误自动重试 3 次；
- **中文可操作报错**：401/403/404/409/413/429/502/503/504 分别给出明确提示（例如「站点反向代理暂时不可用（HTTP 503），已自动重试仍失败，请稍后再试」），不再只抛 `code 503`；
- **导入更稳**：JSON 导入按固定间隔逐条提交，**显示进度**（x/y、失败数），失败逐条给出**原因明细**（原来只累加失败条数）。

## 二、图片体验

- **上传后自检**：上传成功后先确认地址能打开再写入记录，避免"存进去却打不开"（被存储策略或其它插件拦截时立即提示）；
- **上传前压缩（可配）**：超过 1.5MB 的图片在浏览器里压缩到设定宽度（默认 1920）再上传，提示"压缩节省 X MB"；可在「照片设置」关闭；
- **列表用缩略图（可配）**：后台列表、相册网格、前台卡片统一走 Halo 的 `?width=` 小图（默认 480px，仅对本站 `/upload/` 附件生效），点开查看仍是原图；填 0 = 始终原图；
- **一键修复失效引用**：座驾/人员列表标出「含失效图片 N」「大头贴已失效」，相册行提供「重新选择」，并新增「**移除失效图片（N）**」一键清理；前台已自动降级为图标 / 首字 / 占位卡，访客永远看不到破图。

## 三、提醒能力

- **「已办，顺延一期」**：到期项上一键把到期日按循环间隔往后推一期（默认 12 个月），续保 / 年检办完不用手改日期；
- **提醒可逐条忽略**：前台横幅与后台仪表盘小组件每条右侧有「✕」，点一次表示"本次到期周期内不再提示"（存在浏览器里，到期日变化后自动重新提醒），可一键「恢复显示」；可在设置里关闭该能力；
- **年检规则可配置**：新增「座驾设置 → 年检节点（默认 2,4,6,10）」与「从第几年起每年上线检验（默认 11）」——各地 / 各车型规则不同时按当地车管所要求调整；表单预览、前台提醒与依据说明都会同步。

## 四、前台展示

- **爱车视图工具栏**：可按「默认（后台拖拽顺序）/ 到期临近 / 名称」排序，可按「在用车 / 全部（含已出售、已报废）」筛选（纯前端，刷新即回默认）；
- **相册统一比例**：相册大图按 4:3 展示（`object-fit: cover`），浏览时不再因图片尺寸不同而抖动。

## 五、可维护性

- **后台「自检」面板**（页面右上角）：一次看完插件版本、数据量、提醒与展示设置、照片设置命中张数（含是否已放宽）、**图片引用失效数量**、即将到期条数——把"排查靠翻日志"变成一眼可见；
- **设置内「关于」分组**：版本与四条使用提示（强刷、自检入口、图片降级说明、零写入承诺）。
