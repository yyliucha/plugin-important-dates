## 二、一期功能范围（MVP）

### A. 车辆档案（多车）
- **基本**：名称/昵称、品牌、车系型号、车牌号（敏感）、**车辆分类（下拉，见 §2.1）**、能源类型（燃油/纯电/插混/油电混动）、颜色
- **证照**：VIN、发动机号、注册日期、购买日期
- **状态**：当前里程、里程更新时间、状态（在用车/已出售/已报废）
- **相册**：多图；上传/附件库多选、拖拽排序、设封面、删除、**逐张「展示」勾选**
- **关联**：车主（单选人员）、常用驾驶人（多选人员）
- **其他**：备注、前台展示开关（默认关）、重要开关（默认开）、拖拽排序

### A1. 车辆分类清单（下拉固定选项 + 前台图标）

| 分类 | 英文/别称 | 前台图标 |
|---|---|---|
| 轿车 | Sedan | 🚗 |
| SUV | SUV | 🚙 |
| MPV | MPV / 商务车 | 🚐 |
| 跑车 | Sports / Coupe | 🏎️ |
| 越野车 | Off-road / ORV | 🚙 |
| 皮卡 | Pickup | 🛻 |
| 旅行车 | Wagon / Estate | 🚗 |
| 两厢车 | Hatchback | 🚗 |
| 跨界车 | Crossover | 🚙 |
| 微面 / 面包车 | Van | 🚐 |
| 房车 | RV / Motorhome | 🚌 |
| 货车 | Truck | 🚚 |
| 客车 | Bus | 🚌 |
| 摩托车 | Motorcycle | 🏍️ |
| 电瓶车 | E-bike / 电动自行车 | 🛵 |
| 自行车 | Bicycle | 🚲 |
| 其他 | Other | 🚘 |

- 说明：**能源类型**（燃油 / 纯电 / 插混 / 油电混动 / **人力**）与分类相互独立，如"纯电 SUV" = 分类 SUV + 能源 纯电；自行车选"人力"，电瓶车选"纯电"
- 电瓶车/自行车通常**无保险与年检**：到期项均为可选，逐项启用即可（不启用则不提醒）；车牌号、VIN 等字段可直接留空
- 分类仅作展示与筛选（后台列表可按分类筛选；前台卡片显示分类图标），**不影响提醒逻辑**
- 暂不支持自定义分类文本（选"其他"即可）；如后续需要，可加"其他 + 自定义名称"

### B. 到期提醒项（每车多项，逐项开关与提前天数）
| 项 | 字段 | 默认提前 |
|---|---|---|
| 交强险 / 商业险到期 | 保险公司、保单号（敏感）、到期日 | 15 天 |
| 年检到期 | 下次年检日期 | 30 天 |
| 保养提醒 | 上次保养日期/里程、间隔月数/公里 | 14 天 / 500km |
| 车船税 | 到期日 | 15 天 |
| 自定义项 | 名称、日期、提前天数 | 7 天 |

### C. 前台展示
- 「爱车」视图：车辆卡片（封面、名称、品牌型号、**脱敏车牌**、到期徽章、车主/驾驶人统一徽章）；点封面 → 相册浮层（滚动，只读）
- 「生活」视图：重要日期（全部）+ 重要的人（显示与其相关的最近日期倒计时）
- **永不出现**：完整车牌、VIN、发动机号、保单号、购买价格；未勾选「展示」的照片不出现在前台

### D. 数据与管理
- 车辆列表拖拽排序；操作日志记录车辆增删改（`targetType=CAR`）
- 导出/导入 JSON **v3**（含车辆与相册），兼容旧文件
- Finder API：`listAllCars()` / `listUpcomingCarEvents(days)`

### E. 二期候选
统计卡片（车龄/里程/年内到期数）、提醒历史归档、维保记录时间线、多车对比。

## 三、数据模型草案

```
Car (importantdates.halo.run/v1alpha1, plural: cars)
  spec:
    displayName / brand / model / plateNo / vehicleType / energyType / color
    vin / engineNo / registeredDate / purchaseDate
    mileageKm / mileageUpdatedAt / status(IN_USE|SOLD|SCRAPPED)
    photos: [{ url, name, isCover, sortOrder, frontVisible }]   # frontVisible = 前台「展示」勾选
    ownerName（Person.name）/ driverNames[]（Person.name 列表）
    note / visible / important / sortOrder
    reminders: [{ key, label, date, remindDays, enabled,
                  insurer, policyNo, intervalMonths, intervalKm,
                  lastServiceDate, lastServiceKm }]
```

设置页新增「车辆设置」组：全局默认提前天数、启用提醒项、车辆照片附件分组（策略+分类，复用实时下拉）、前台展示车辆区块、**性别皮肤开关（默认开）**、弹窗条数与合并规则。

## 五、皮肤与统一徽章

| 场景 | 风格 | 设计方向 |
|---|---|---|
| 车主 = 男 | **酷** | 碳纤维深灰底、冷色高光（蓝/银）、直角硬朗、速度线、齿轮元素 |
| 车主 = 女 | **可爱** | 奶油/粉彩底、大圆角、爱心/星星点缀、柔和渐变 |
| 未关联/性别保密 | **中性** | 与现有卡片统一 |

- **统一徽章**：车辆卡片与其对应人（车主/驾驶人）使用同一套配色与徽章样式，视觉上归属关系一目了然
- 实现：纯 CSS 变量 + 类名（零图片资源）；多人时以车主为准，无车主取第一位驾驶人
- 可选叠加（二期）：按能源类型配色

## 六、提醒整合与文案

1. **统一计算**：日期事件 + 车辆到期事件同一列表，**按剩余天数升序**（同级日期优先）
2. **分渠道开关**：仪表盘小组件 / 后台横幅 / 前台横幅（仅前台可见项）/ 全站悬浮弹窗
3. **降噪**：每类型最多 N 条（默认 2）、超出合并（"「交强险」明天到期，另有 2 项 7 天内到期"）
4. **文案（生活化、有人情味）**：
   - "「小白」的保险还有 7 天到期，记得安排一下呀～"
   - "「爷爷」的生日就是今天呀 🎉"
   - 空状态："还没添加爱车，先记一辆吧～"

## 七、命名与应用市场

**显示名「记得」**，副标题：记得 · 重要日期与爱车 —— 纪念日、生日提醒 · 家人档案 · 车辆保险年检保养

- **技术约束**：只改 `displayName`，**绝不改插件 ID**（改 ID = 新插件：数据不兼容、需重装）
- **商店影响**：ID 为主键，displayName/简介/README/截图属元信息；已上架应用改元信息通常需**重新提交变更审核**（以平台规则为准），无需下架重发
- **执行方式**：与 1.2.0 版本提交**一并完成**，版本说明写明"应用更名为「记得」，功能不变"，一次审核完成
