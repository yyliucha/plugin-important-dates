## 二、一期功能范围（MVP）

### A. 车辆档案（多车）
- **基本**：名称/昵称、品牌、车系型号、车牌号（敏感）、类型（轿车/SUV/MPV/皮卡/摩托/其他）、能源类型（燃油/纯电/插混/油电混动）、颜色
- **证照**：VIN、发动机号、注册日期、购买日期
- **状态**：当前里程（km）、里程更新时间、状态（在用车/已出售/已报废）
- **相册**：多图；支持上传/附件库多选、拖拽排序、设封面、删除；**每张可标记「前台可见」（默认开）**
- **关联**：车主（单选人员）、常用驾驶人（多选人员）— 可选
- **其他**：备注、前台展示开关（默认关）、重要开关（默认开，参与提醒）、拖拽排序

### B. 到期提醒项（每车多项，逐项开关与提前天数）
| 项 | 字段 | 默认提前 |
|---|---|---|
| 交强险到期 | 保险公司、保单号（敏感）、到期日 | 15 天 |
| 商业险到期 | 同上 | 15 天 |
| 年检到期 | 下次年检日期 | 30 天 |
| 保养提醒 | 上次保养日期/里程、间隔月数/公里 | 14 天 / 500km |
| 车船税 | 到期日 | 15 天 |
| 自定义项 | 名称、日期、提前天数 | 7 天 |

### C. 前台展示
- 「爱车」视图：车辆卡片（封面、名称、品牌型号、**脱敏车牌**、到期徽章、车主/驾驶人）；点封面 → **相册模式**（滚动查看，只读）
- 「生活」视图：重要日期 + 重要的人（卡片显示与其相关的最近日期倒计时）
- **永不出现**：完整车牌、VIN、发动机号、保单号、购买价格；标记「仅后台」的照片不进入前台相册

### D. 数据与管理
- 车辆列表拖拽排序；操作日志记录车辆增删改（`targetType=CAR`）
- 导出/导入 JSON **v3**（含车辆与相册），兼容旧文件
- Finder API：`listAllCars()` / `listUpcomingCarEvents(days)`

### E. 二期候选
统计卡片（车龄/里程/年内到期数）、提醒历史归档、维保时间线、多车对比。**费用台账不做。**

## 三、数据模型草案

```
Car (importantdates.halo.run/v1alpha1, plural: cars)
  spec:
    displayName / brand / model / plateNo / vehicleType / energyType / color
    vin / engineNo / registeredDate / purchaseDate
    mileageKm / mileageUpdatedAt / status(IN_USE|SOLD|SCRAPPED)
    photos: [{ url, name, isCover, sortOrder, frontVisible }]   # 相册（含"前台可见"标记）
    ownerName（Person.name）/ driverNames[]（Person.name 列表）
    note / visible / important / sortOrder
    reminders: [{ key, label, date, remindDays, enabled,
                  insurer, policyNo, intervalMonths, intervalKm,
                  lastServiceDate, lastServiceKm }]
```

设置页新增「车辆设置」组：全局默认提前天数、启用哪些提醒项、车辆照片附件分组（策略+分类，复用实时下拉）、前台展示车辆区块、**性别皮肤开关（默认开）**、弹窗显示条数与合并规则。

## 四、前台页面方案

路由保持 `/important-dates`（兼容旧链接与主题覆盖模板），顶部**生活化切换器**：

```
[ 生活 ]  [ 爱车 ]     ← 默认「生活」，写入 URL ?view=car（刷新/分享保持）
────────────────────────────
横幅提醒（随视图变化，按剩余天数升序，谁近谁靠前）
────────────────────────────
生活视图：重要日期（全部）＋ 重要的人（显示与本人相关的最近日期倒计时）
爱车视图：车辆卡片（封面/脱敏车牌/到期徽章/车主与驾驶人）＋ 重要的人（标注「车主/驾驶人」）
         点卡片封面 → 相册模式（滚动查看，只读；Esc/× 关闭）
```

- **人员区块两个视图都保留**；区别在卡片承载的语义
- 主题覆盖模板新增变量：`view`、`cars`、`carEvents`、`carOwners`
- 设置项：是否显示切换器、默认视图

## 五、性别卡片皮肤（默认开启）

| 场景 | 皮肤 | 设计方向 |
|---|---|---|
| 车主 = 男 | **酷** | 碳纤维深灰底、冷色高光（蓝/银）、直角硬朗、速度线、齿轮/轮胎元素 |
| 车主 = 女 | **可爱** | 奶油/粉彩底、大圆角、爱心/星星点缀、柔和渐变、圆润图标 |
| 未关联/性别保密 | **中性** | 与现有卡片统一 |

- 实现：纯 CSS 变量 + 类名，零图片资源；多人时以**车主**性别为准，无车主取第一位驾驶人
- **待确认范围**：A 仅车辆卡片（推荐）/ B 车辆卡片 + 人员徽章（推荐叠加）/ C 整页风格
- 可选叠加：按能源类型配色（电车=环保绿、燃油=机械橙）

## 六、提醒渠道与排序

1. **统一计算**：日期事件 + 车辆到期事件进同一列表，**按剩余天数升序**（谁近谁靠前；同级日期优先）
2. **分渠道开关**：仪表盘小组件 / 后台横幅 / 前台横幅（仅"前台可见"项）/ 全站悬浮弹窗
3. **降噪**：每类型最多 N 条（默认 2）、超出合并汇总（"「交强险」明天到期，另有 2 项 7 天内到期"）
4. **文案基调（生活化、有人情味）**：
   - "「小白」的保险还有 7 天到期，记得安排一下呀～"
   - "「爷爷」的生日就是今天呀 🎉"
   - 空状态："还没添加爱车，先记一辆吧～"

## 七、命名方案

**推荐：显示名「记得」**，副标题「记得 · 重要日期与爱车 —— 纪念日、生日提醒 · 家人档案 · 车辆保险年检保养」

| 候选 | 评价 |
|---|---|
| **记得** ⭐ | 简洁口语、有情感，覆盖人/日子/车三种场景 |
| 念念 | 文艺（念=纪念/挂念），检索性弱 |
| 重要日子与爱车 | 一眼看懂、搜索友好，但稍长 |
| 生活册 / 日子 | 中性 / 过泛 |

**技术约束**：只改 `displayName`，**绝不改插件 ID**（等于新插件：数据不兼容、需重装）。

**应用市场影响**：ID 为主键，displayName/简介/README/截图属可变更元信息；已上架应用改元信息通常需**重新提交变更审核**（以平台规则为准），无需下架重发。**建议与 1.2.0 版本提交一并完成**，一次审核。
